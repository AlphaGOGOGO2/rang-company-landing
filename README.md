# Rang Company Landing

Next.js landing page for 주식회사 랑, a food distribution company focused on wholesale, retail, consignment, delivery, and export.

## Scripts

```bash
npm run dev
npm run build
npm run start
```

## SEO

The site includes canonical metadata, Open Graph/Twitter metadata, `robots.txt`, `sitemap.xml`, static social preview image, and JSON-LD for Organization, LocalBusiness, WebSite, and FAQPage.

Set `NEXT_PUBLIC_SITE_URL` to the production domain before production deployment.
